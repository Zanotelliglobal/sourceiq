## Objective

Extend the repository write path from ONE call site (proven by Plan 03-01's tracer inside `makeProcessSupplier`) to the two remaining call sites — `makeProcessSupplierQuick` (quick-scan discovery) and `makeProcessSupplierDeepen` (deepen re-verify) — so that REPO-02 (every discovery path writes through the shared repository) is fully satisfied.

**Purpose:** REPO-02 explicitly requires that "every supplier discovered via quick scan, full investigation, or (once built) RFP matching is written into the repository through a single shared write path." Plan 03-01 covered full investigation; this plan covers the other two.

**Output:** All three `makeProcessSupplier*` functions in `lib/process-supplier.ts` call the same three `lib/supplier-repository.ts` helpers with the appropriate arguments for their flow's information state (quick-scan: no ai_score/category; deepen: has both, plus later enrichment).
