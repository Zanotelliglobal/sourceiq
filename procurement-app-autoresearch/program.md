# Program — procurement-app

## Goal
Iterate SourceIQ's one-page product strategy toward the best possible app for
procurement professionals: super effective, dead simple, and monetizable.

## What is iterated
A single-page product strategy with fixed sections:
1. ICP (who exactly, narrow)
2. Killer workflow (the one job it nails, end to end)
3. Simplicity promise (what the user does NOT have to do)
4. Monetization (pricing model + why it compounds)
5. Wedge & moat (why this over incumbents AND raw ChatGPT)
6. Proof / first "wow"

## Iteration rules
- Change ONE section per iteration (atomic).
- Direction: sharper, narrower ICP, bolder wedge, clearer money.
- No hedging. Discard changes that broaden or qualify.
- Must remain buildable on the current stack (Next.js + Anthropic SDK +
  Neon + Clerk + Stripe + Resend) and self-serve (no 6-month sales cycle).

## Priority order for changes
1. Money (WTP + model) — nothing matters if it doesn't pay.
2. Pain Kill / ICP narrowing.
3. Wedge/moat vs incumbents + ChatGPT.
4. Time-to-value / simplicity.
